fluxswitch

Version switcher for the Flux CLI, in Go
github.com/everythingisacomputer/fluxswitch · MIT

Switch between versions of the Flux CLI the way tfswitch does for Terraform: one command to download, verify, and activate any release.

  • Interactive terminal picker (bubbletea) — installed versions first, arrow keys, fuzzy search, single-key download and uninstall.
  • Every download is verified against the release’s published SHA-256 checksums before it touches disk.
  • Switching atomically repoints a symlink, so flux always resolves — even mid-switch.
  • Distributed via GitHub releases and a Homebrew tap serving macOS and Linux from one formula.
  • CI gates every release behind unit tests, govulncheck, and gosec.
$ brew tap everythingisacomputer/tap
$ brew install fluxswitch
$ fluxswitch 2.9.3
Downloading flux 2.9.3...
Switched flux to 2.9.3 (~/.fluxswitch/bin/flux)

fluxboost

Flux GitOps repository scaffolder, in Go
github.com/everythingisacomputer/fluxboost · MIT

Scaffold Flux GitOps repositories with opt-in platform services, SOPS secrets encryption, and namespace-scoped tenants, for AWS, GCP, and bare metal clusters.

  • Interactive init wizard (huh) that scaffolds a clusters → overlays → services layout, recorded in fluxboost.yaml as the source of truth for every later command.
  • Opt-in platform service registry — cert-manager, Istio, external-secrets, external-dns, Vault, Kubecost, and more — with hard requirements auto-added and dependsOn chains filtered to your selection.
  • Provider-aware rendering for AWS, GCP, and bare metal: DNS01 solvers, Workload Identity / IRSA annotations, and external-dns wired per provider.
  • Grows with the repo: env add, service add/remove, namespace-scoped tenant add, and app add with optional Flux image automation.
  • fluxboost check builds every kustomization with an embedded kustomize and flags undefined substitution variables before Flux ever sees them.
$ brew tap everythingisacomputer/tap
$ brew install fluxboost
$ fluxboost init platform
$ fluxboost tenant add team-a
$ fluxboost check

Design based on The Monospace Web by Oskar Wickström.
